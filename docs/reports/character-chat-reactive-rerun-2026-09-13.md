- 외부 호출 전에 캐릭터·사용자 생성 양쪽의 매개변수를 최신 제공자 지원 목록과 대조했다.
- 실패 시 상태·코드만 자격 증명 없이 보존하도록 했다. 이번 실제 실행에는 실패가 없었다.
- 모델·캐릭터 자료·시나리오·시각·제공자 고정·가격 상한은 유지했다. 이전 실패 원문과 새 실행은 분리했다.

기존 대화 실행기, JSON 처리기, 제품 HTTP 경로와 DB 검색을 재사용했다. 이번 변경은 실행용
