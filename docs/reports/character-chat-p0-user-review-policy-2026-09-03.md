## 결론

사용자 리뷰에서 반복된 결함을 캐릭터별 문구가 아니라 공통 답변 정책으로 반영했다. Persona와
게시물은 캐릭터의 판단과 말투를 형성하지만, 사용자 발화와 무관한 소재를 꺼내기 위한 목록으로
사용하지 않게 했다. 근거 없는 구체적 현재 활동, 인터뷰·상담형 질문, 번역투·상품 설명·설명 없는
업계 표현도 같은 공통 정책에서 억제한다.

이번 변경은 특정 정답 문장이나 good/bad 예시를 prompt에 넣지 않는다. 사용자 리뷰가 지적한 원인을
원칙으로 일반화해, 다른 캐릭터와 새로운 상황에도 같은 판단 순서가 적용되게 했다.

## 사용자 리뷰와 구현 규칙의 대응

| 사용자 리뷰에서 반복된 문제 | 공통 응답 규칙 |
| --- | --- |
| 날씨·방문 장소·유입 경로처럼 뜬금없는 전제 | 직전 사용자 발화에 먼저 반응하고, 위치·상황·의도를 입력 없이 추정하지 않는다. |
| 촬영·수업·운동·게시물 소재를 대화보다 앞세우거나 한 소재로 계속 복귀 | Persona, canon, memory, profile, post, 직업과 취미는 반응을 형성하는 배경이며 화제 목록이 아니다. 대화가 이동한 뒤 같은 대표 소재로 되돌아가지 않는다. |
| `뭐 해?`에 구체적인 현재 업무를 사실처럼 생성 | 현재 활동 정본이 없으면 일상적이고 낮은 구체성으로 답하며 배경 설정을 현재 사실로 변환하지 않는다. |
| 질문 공세와 상담 응대 | 질문은 선택 사항이며 직전 발화에서 직접 이어질 때만 사용한다. 짧은 반응이나 의견도 충분한 답으로 인정한다. |
| 비문·번역투·상품 설명·업계 용어 | 한국어 채팅에서는 일상 표현을 우선한다. |
| 반말·존댓말 혼용을 일괄 오류로 판정 | Persona와 관계 단계에 맞으면 허용하고, 변화가 캐릭터답고 의도적으로 느껴지는지만 본다. |

## 증명한 것과 아직 증명하지 않은 것

증명한 것은 사용자 리뷰를 일반화한 공통 정책이 실제 system prompt에 올바른 순서로 조립되고,
기존 채팅 서비스 테스트·타입·빌드를 깨뜨리지 않으며, 특정 캐릭터에게 귀속되지 않았다는 점이다.

아직 증명하지 않은 것은 실제 모델 출력의 자연스러움 개선이다. 승인 범위에 따라 외부 모델과 개발
DB를 호출하지 않았으므로 새 transcript가 없다. 기존 자동 judge는 사용자 판정과 크게 어긋났기 때문에
새 실행에서도 자동 PASS를 성공 근거로 사용하면 안 된다. 다음 모델 비교를 수행한다면 동일한 공통
시나리오를 다시 생성하고, 이 22개 사용자 기준에 대응하는 결함의 재발 여부를 그대로 보여줘야 한다.

## Calibration 상태

추가 reviewer와 blind review는 보류했지만 관련 tooling과 엄격한 gold 승격 조건은 유지했다. 현재
자료는 계속 `reviewerCount: 1`, `blind: false`, `method: posthoc`, `seed/uncalibrated`다. 이 보고서는
이를 gold, adjudicated 또는 calibrated 결과라고 부르지 않는다.
