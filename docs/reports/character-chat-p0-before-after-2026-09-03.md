# 캐릭터 챗 P0-R1 전후 대화 검수 보고서

- 작성일: 2026-09-03
- 범위: 개발 DB 활성 캐릭터 4명, 공통 응답 정책 변경 전후
- 판정 상태: **사용자 검수 대기** — 자동 점수는 자연스러움 합격 근거로 사용하지 않음

## 한눈에 보기

| 항목 | 결과 |
| --- | --- |
| 개발 DB 스냅샷 | 활성 캐릭터 4명, Persona 45블록, Canon 79개 |
| 새 전체 대화 | 8/8 대화, 48/48 응답 완주 |
| 같은 보이는 문맥 재생 | 사용자 리뷰로 선택한 25/25 응답 완주 |
| 후보 모델 | `xiaomi/mimo-v2.5-pro` |
| 전체 대화 simulator | `gpt-5.6-luna` |
| Judge | 사용 안 함 |
| 새 답변 품질 라벨 | 없음 |

실행기의 `quality=PASS`와 각 trajectory의 `CONNECTED`는 judge가 없는 smoke에서 완료·비어 있지 않음 등 기계적 조건이 통과했다는 뜻이다. 자연스러움 PASS가 아니다.

### 검수 순서

1. 먼저 ‘같은 보이는 문맥 재생 25개’에서 같은 사용자 발화에 대한 이전 답변과 수정 후 답변만 비교한다.
2. 그다음 ‘새 전체 대화 8개’에서 주제 전환, 질문 반복, Persona 소재 반복 같은 흐름을 본다. 이쪽은 사용자 발화가 달라 직접 A/B로 판정하지 않는다.
3. 수정 후 답변은 모두 무라벨이다. 특히 반말·존댓말 혼용은 그 자체로 실패 처리하지 않고 Persona와 관계 맥락에 따라 본다.

### 바로 확인되는 미해결 지점

기존 사용자 리뷰에서 선택된 문구가 수정 후에도 그대로 남은 사례가 있다.

- human-004: `그날이 있죠`
- human-006: `오, 왔네요. 반가워요.`
- human-020: `셀렉 보고 있어요.`

따라서 25회 완주는 품질 통과가 아니다. 이 목록은 새 평가 기준을 추가한 것이 아니라, 사용자가 이미 실패로 지적한 문자열의 잔존 여부만 확인한 것이다.

## 비교 설계

9월 2일 실행 뒤 평가 시나리오가 바뀌어 새 전체 대화의 사용자 발화 48개 중 36개가 이전과 다르다. 따라서 8개 전체 대화는 자연스러운 흐름을 보는 자료로만 사용하며, 변경 효과의 직접 비교로 해석하지 않는다.

직접 비교는 사용자가 남긴 22개 리뷰만 선택 근거로 삼았다. 턴 리뷰 15개와 대화 전체 리뷰 2개의 모든 턴을 합친 25개 지점에서 9월 2일의 보이는 대화 prefix를 그대로 재생했다. 관계 상태와 사용자 메모리는 각 지점에서 초기화했으므로, 이는 동일한 **보이는 문맥의 국소 응답 비교**이지 장기 관계 상태까지 동일한 실험은 아니다.

## 데이터 및 실행 격리

- 개발 DB는 `default_transaction_read_only=on`으로 읽었다.
- 활성 `characters`, 활성 `character_personas`, 활성 `character_memories`만 SSH binary COPY 스트림으로 일회용 로컬 PostgreSQL에 옮겼다.
- 사용자 대화, 사용자 메모리, 개인정보, `admin_settings`는 복제하지 않았다.
- API 키는 실행 프로세스 환경에서만 사용했으며 결과 파일에 기록하지 않았다.
- 로컬 대상의 Persona 연결도 `transaction_read_only=on`, 사용자 Memory와 Job Queue는 임시 메모리 저장소, 도구는 비활성화했다.
- 검증 종료 후 일회용 PostgreSQL 컨테이너, 평가 서버, 임시 실행 스크립트와 로그를 제거했다. 아래 결과 artifact와 문서만 남겼다.

## 실행 중 발생한 오류

- 준비 파일 경로 오류: 모델 호출 전 중단, 외부 호출 0회.
- API URL 정규화 누락: OpenRouter의 잘못된 경로로 첫 턴 요청 8회가 전송되어 HTTP 404로 종료. 완료 응답과 simulator 호출은 0회. 실패 결과는 `attempt-404`에 보존했다.
- 재생 스크립트 모듈 형식 오류: 모델 호출 전 중단, 외부 호출 0회.
- 수정 후 완료: 전체 대화 후보 48회 + simulator 32회, 같은 문맥 후보 25회.
