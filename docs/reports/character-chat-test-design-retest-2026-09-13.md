## 후속 실제 실행 — 중단

사용자의 “해” 승인 후 외부 재시험을 시작했다. 캐릭터 답변 1개를 생성했고, 그 답변에 반응하는 사용자
발화 생성 요청에서 오류가 나 실행을 중단했다. **24답변 재시험 완료가 아니다.**

- 요청 시도: 2회. 완료: 캐릭터 답변 1개, 생성 사용자 발화 0개. 재시도 0회.
- 확인된 과금: $0.001224525. 실패 요청 과금은 확인되지 않았고, 두 요청의 전체 보수적 예약액은
  $0.0130095다. 실패 요청을 과금 0으로 추정하지 않았다.
- 설정 결함: 사용자 발화 생성 요청의 `seed`는 실행 직전 조회한 Xiaomi 지원 목록에 없다.
  `require_parameters: true`를 쓰면서 이를 사전 검사하지 못했다. 원래 HTTP 오류가 보존되지 않아
  정확한 원격 오류 코드·직접 원인까지 확정하지는 않는다.
- 로컬 조치: `seed`만 제외한 요청을 별도 파일로 만들고, 남은 매개변수가 지원 목록에 있는지와
  이전 실제 답변·가격 상한·제공자 고정이 유지되는지 검증했다. 수정 요청은 **미전송**이다.
- DB 9개 테이블 전후 동일. 완료 답변의 요청 해시·원문·5개 주입 페르소나 본문을 확인했다.
- 새 답변 1개는 사용자 미검수다. 전체 자연스러움·캐릭터 차이·개선율에 대한 결론은 없다.

DB 구조, 개발 서버와 배포에는 손대지 않았다. 기존 작업 트리에 있던 다른 제품 변경도 이번 수정으로

## 아직 하지 않은 검증과 다음 실행

- 실제 LLM으로 4캐릭터 × 2상황 × 최대 3왕복, 캐릭터 답변 최대 24개.
- 후속 사용자 발화 생성 최대 16회 포함, 합계 최대 40회·$1 이내·재시도 없음.
- 기존과 같은 OpenRouter/Xiaomi `mimo-v2.5-pro`를 제안했다. 외부 전송 대상은 로컬 캐릭터 설정·메모리와
  합성 대화뿐이며 실제 사용자 대화는 제외한다. 이후 사용자가 승인하여 실행했지만 위와 같이 중단됐다.
- 승인 후에는 답변마다 실제 대화 전체·관계·주입 페르소나·주입/제외 메모리·요청 해시를 함께 기록하고
  검수 화면으로 제공한다. 구조 확인용 고정 응답을 검수용 실제 답변으로 올리지 않는다.
- 이번 파일럿은 새 시험 방식의 유효성을 먼저 보는 단일 조건 소표본이다. 전후 동일 문맥 A/B, 장기 기억,
  관계 발전, 임베딩·벡터 검색, 메모리 저장·통합은 검증하지 않는다. 정정·망각은 기존 사용자 결정대로 미룬다.

현재는 사용자 메모리를 대화별 임시 저장소에 격리했고 장기 메모리 통합·임베딩 호출은 껐다. 따라서
“페르소나/메모리 아키텍처 전체 검증 완료”도 결론으로 내리지 않는다.
