# 캐릭터 챗 P0 스모크 사람 검수 Overlay

- 검수일: 2026-09-02
- 근거: 사용자가 발화 원문에 남긴 22개 주석
- 적용 방식: 원본 자동 점수와 PASS/FAIL은 보존하고, 명시적 사람 판정을 별도 overlay로 기록
- 한계: 전체 blind calibration이 아니라 자동평가 결과를 본 뒤 수행한 사후 검수

## 판정 변경

| 캐릭터·시나리오 | 자동 판정 | human-adjusted | 근거 |
| --- | --- | --- | --- |
| 한소이·첫 대화 | PASS | **FAILURE** | 짧은 인사 직후 날씨 화제로 비약 |
| 서린·첫 대화 | FAIL | **FAILURE** | 문맥 없는 질문, 잘못된 표현, 문맥 불일치 |
| 권도건·첫 대화 | PASS | **FAILURE** | 어색한 인사와 문장, 직업 설정 과다 설명 |
| 나희·첫 대화 | PASS | **FAILURE** | 문맥 비약, 상품 설명 같은 게시물 의존, Persona 부적합 |
| 한소이·현재 상태 | FAIL | **FAILURE** | 어색한 문장과 게시물·Persona 설정 설명 |
| 서린·현재 상태 | FAIL | **FAILURE** | 촬영 화제 편중과 placeholder 노출 |
| 권도건·현재 상태 | FAIL | **FAILURE** | 근거 없는 현재 수업·커피 상태 생성; 별도 사람 override 없음 |
| 나희·현재 상태 | FAIL | **FAILURE** | 비일상적 표현과 어색한 문장 구사 |

자동 PASS 3건이 모두 사람 검수에서 뒤집혔다. 기존 자동 FAIL 5건을 유지한 human-adjusted 결과는 **0/8**이다. 이 수치는 전체 blind review pass rate가 아니라 명시적 override를 반영한 진단값이다.

## 평가 기준 수정

1. **문맥 연결성:** 직전 사용자 발화로부터 자연스럽게 이어지지 않으면 짧고 친근해도 실패 후보로 본다.
2. **자연스러운 한국어:** 문법, 어순, 관용 표현, 의미 연결을 `dm_style`과 분리해 평가한다.
3. **Persona 발화 개연성:** Persona 정보를 언급했다는 이유로 점수를 주지 않고, 해당 캐릭터가 실제로 할 법한 반응인지 본다.
4. **소스 과의존 억제:** 게시물·프로필의 상품명, 촬영, 직업 소재를 답변 템플릿처럼 재연하면 감점한다.
5. **화제 다양성:** 서린의 촬영처럼 한 가지 대표 소재가 대화를 독점하는지 캐릭터별로 측정한다.
6. **말투 혼용의 조건부 평가:** 반말·존댓말 혼용은 전역 오류가 아니다. Persona와 관계 단계에서 허용된 패턴을 벗어나거나 턴 사이에서 이유 없이 흔들릴 때만 실패로 본다.
7. **Human override 보존:** 자동 PASS와 사람 FAILURE가 충돌하면 원본 점수는 남기되 calibration mismatch로 기록한다.

## 구현 반영 상태

2026-09-02에 다음 P0 평가 변경을 반영했다.

- Diagnostic judge에 `local_relevance`, `natural_korean`, `persona_without_motif`를 추가했다.
- Diagnostic `dm_style`은 표면 형식만 담당하도록 설명을 한정했다.
- 반말·존댓말 혼용은 Persona와 관계에 따라 조건부로 평가한다.
- 게시물·프로필·상품·직업·취미 소재의 카탈로그식 재연과 대표 화제 반복을 감점 대상으로 명시했다.
- Simulator가 어색한 답을 대신 구조하거나 근거 없는 세부를 받아 주지 않게 하고, 미래 scripted
  beat의 실제 문구를 미리 보지 못하게 했다.
- Opening fixture의 `심심해서` 반복 원인을 scripted beat와 backstory에서 제거하고, 4턴을
  `그냥 아무 얘기나 하자 ㅋㅋ`로 바꿨다.
- 8개 trajectory 판정과 이 문서의 22개 주석을 typed calibration seed로 저장했다.

구현 소유자는 공통 평가 계층이며 캐릭터 이름·ID·전용 규칙을 코드에 추가하지 않았다. 변경 파일은

[`evals/cases/character-naturalness-baseline.json`](../../evals/cases/character-naturalness-baseline.json),

## 현재 결론과 남은 검증

이 변경은 평가기의 false-pass를 줄이기 위한 P0 보정이지 production 답변 개선이 아니다. 기존 스모크
원문으로 확인된 결과는 자동 PASS 3건이 모두 사람 FAIL인 **0/8 human-adjusted**이며, 현재 judge를
자연스러움 품질 gate로 신뢰할 수 없다.

현재 calibration artifact도 `seed/uncalibrated`다. 한 명이 자동 결과를 본 뒤 검수했으므로
adjudicated gold로 승격할 수 없다.

2026-09-03에 사용자는 추가 reviewer 없이 본인이 남긴 이 22개 주석만으로 개선을 진행하도록
결정했다. 따라서 2인 blind review와 judge-human agreement 계산은 삭제한 것이 아니라 **보류**했고,
이번 iteration에서 새 품질 판정이나 추가 사람 의견을 개선 입력으로 섞지 않는다.

이 결정에 따라 production stable prompt의 공통 응답 정책에는 다음을 반영했다.

- 직전 사용자 발화와 직접 연결되는 반응을 먼저 한다.
- 사용자 위치·방문 이유·현재 상황을 입력 없이 추정하지 않는다.
- Persona, canon, memory, profile, post, 직업과 취미를 화제 목록처럼 꺼내지 않는다.
- 대화가 다른 곳으로 이동했는데도 같은 대표 소재로 계속 돌아가지 않는다.
- 현재 활동 정본이 없으면 구체적인 활동을 배경 설정에서 만들어 사실처럼 말하지 않는다.
- 질문·상담 응대를 기본 턴 구조로 사용하지 않는다.
- 한국어 대화에서는 번역투·상품 문구·설명 없는 업계 표현보다 일상 표현을 우선한다.
- 반말·존댓말 혼용은 전역 오류로 보지 않고 Persona와 관계에 따라 판단한다.

이 정책은 캐릭터 이름·ID·전용 motif를 포함하지 않으며 모든 캐릭터가 같은 생성 경로에서 적용받는다.
이번 범위에는 외부 모델 재호출이 없으므로, 정책 반영 사실과 코드 회귀 통과까지만 주장한다.
“답변이 자연스러워졌다”는 결론은 변경 후 transcript를 사용자 기준으로 다시 비교하기 전까지 보류한다.
