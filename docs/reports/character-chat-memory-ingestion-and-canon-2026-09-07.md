## 결론

이번에는 답변 문구만 바꾸지 않고, 기억 저장과 캐릭터 기억의 읽기 구조를 수정했다.
구현과 자동 검증은 통과했지만 **자연스러움의 최종 목표를 달성한 상태는 아니다**.
공통 데이터 계약 변경이므로 병합 전 검토가 필요하다. 개발 서버에 배포하지 않았다.

| 수정한 것 | 이전 문제 | 현재 동작 |
| --- | --- | --- |
| 사용자 기억 추출 | “기억할 정보 없음” 같은 설명문도 중요도 5의 사용자 사실로 저장될 수 있었음 | 완전한 배열과 유효한 항목만 저장. `[]`는 기억 없음으로 처리 |
| 모델 응답 완료 확인 | 잘린 응답을 정상 텍스트로 취급 | 잘림·거절·도구 호출·응답 누락을 저장 전에 거부 |
| 기억에서 얻은 추론 | 출처 번호가 없거나 잘못돼도 저장되고 사용자 요약에 전달될 수 있었음 | 실제 제공한 근거 번호가 필요. 잘못된 묶음은 저장·요약 입력으로 넘기지 않음 |
| 캐릭터 기억 읽기 | DB의 ID·분류·기록 시각을 버리고 문장만 읽음 | 원문에 ID·분류·작성 이유·등록/수정 시각을 함께 보존. 기존 문장 입력도 호환 |
| 페르소나 비교 도구 | 선택 자료가 0개인 비교만 가능 | 상황별로 필요한 자료를 미리 지정한 비교도 가능. 다른 캐릭터·금지 자료·누락 설정은 실행 전에 차단 |

캐릭터 이름이나 직업을 조건으로 삼는 제품 코드는 추가하지 않았다. 실제 캐릭터별 ID는
Git에서 제외한 실험 입력에만 있다. 전체 background block을 선택 대상으로 둔 이번 진단을
최종 Persona 분류 정책으로 채택하지 않았다.

## 무엇을 확인했나

- 잘못된 기억 추출 뒤에는 새 사실·중요도 증가·대화 요약 진전이 없다. 같은 작업을 정상 응답으로
  다시 시도하면 한 번만 저장된다. 정상 기억과 근거가 있는 추론을 모두 버리는 구현도 아니다.
- 실제 DB 테스트에서 캐릭터 기억의 미세한 등록 시각과 정렬 순서를 보존했다. 삭제된 항목과
  다른 캐릭터의 항목은 가져오지 않았다. 합성 데이터는 트랜잭션을 되돌려 남기지 않았다.
- 캐릭터 4명의 기억 79개를 구조화해도 모델에 주는 프롬프트는 이전과 완전히 동일했다.
  내부 ID·작성 이유·시각을 답변 모델에 새로 노출하지 않았다.
- 실제 설정을 사용한 구조 진단 56건을 통과했다. 직접 관련 질문의 지정 자료 4건, 앞 문맥을
  참조하는 진단 2건이 들어갔고 중립 인사·주제 종료에서는 지정 자료가 들어가지 않았다.
  선택 정답은 사전에 지정했으므로 **자동 선택기의 정확도를 증명한 것은 아니다**.

| 자동 검사 | 결과 |
| --- | --- |
| 제품 테스트 최종 실행 | **338건 모두 통과** — 실제 로컬 DB 통합 15건 포함 |
| 평가 도구 테스트 | 91 통과 |
| 코드 검사·타입 검사·빌드·미사용 코드 검사 | 통과 |
| 웹 테스트 | 37 통과, 웹 타입 검사 통과 |
| 제품 / 기존 평가 coverage gate | 92.35% / 85.16%, 통과 |
| 실제 설정 기반 합성 경로 검사 | 56건, 외부 모델 호출 0회 |
| 사용자 Memory 유효성 정책 검사 | **FAIL 유지** — 아래 정정·망각 상태 구조가 아직 없음 |

coverage 실행은 DB 미연결 조건의 제품 323건(15 skip)을 사용했고, 이후 실제 로컬 DB를 연결한
제품 전체 338건을 별도로 통과했다. 평가 coverage는 기존 설정이 지정한 scoring/schema 등의 범위다. 모든 CLI의 코드 coverage나
대화 품질 점수를 뜻하지 않는다. 테스트용 429 오류 로그는 실패 처리·재시도 0 검사의 예상 출력이다.

## 아직 해결되지 않은 것

1. 문법적으로 정상인 기억이 **실제로 사용자가 말한 사실인지**의 의미적 검증.
2. 오래되거나 정정·망각된 기억을 저장소부터 사용자 요약, 대화 요약, 기록, 대기 작업까지
   일관되게 처리하는 기능. 검색 결과에서만 감추면 완료가 아니다.
3. 캐릭터 기억의 전량 주입, 실제 페르소나 자동 선택, 과거 사건과 현재 상태의 구분.
4. 동일 모델·제공사·추론 조건에서 만든 실제 답변의 사용자 검수, 긴 대화, 지연·비용 기준.

등록/수정 시각은 사건이 일어난 시각이나 만료 시각이 아니다. 분류가 `event`이거나 작성 이유가
`auto:`라는 이유만으로 현재 활동이라고 단정하지 않는다. 유효한 출처 번호 역시 내용의 진실성을
보장하지 않는다. 현재 [최종 기준 G1~G7](../character-chat-products-persona-memory-research-2026-09-03.md#106-최종-목표-달성-기준-v1-2026-09-07-수립)은 모두 미검증이다.

실제 사용자 대화·사용자 기억·인증 정보는 반입하지 않았다. 이전 환경의 모델 응답 12건은
